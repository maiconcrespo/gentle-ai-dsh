# v1

First usable release of the gentle-ai dsh plugin bundle. Issue: maiconcrespo/gentle-ai-dsh#1.
Branch `feat/1-v1`; delivered through a PR that closes #1.

## Specs

- S1. Workflow: "Si siempre con un issue y luego PR". Issue #1 is the spec source; the PR must reference it (`Closes #1`).
- S2. Engram optional (issue #1, scope 1): "If the `engram` executable is missing, dsh still boots with the plugin, without memory, and the user gets a clear message on how to install Engram. The plugin never downloads binaries." Install command: `brew install gentleman-programming/tap/engram` (homepage https://github.com/Gentleman-Programming/engram).
- S3. Content sync (issue #1, scope 2): "A script pulls the persona and skills from a pinned gentle-ai ref (tag or commit) instead of hand-copying them. Updating means bumping the pin and re-running the script. The pinned ref is recorded in `NOTICE`." Pin: gentle-ai `v4.4.0`.
- S4. Skills (issue #1, scope 3): "Ship every skill from gentle-ai's `skills/` directory that passes dsh validation (kebab-case `name`, `description`), not only `comment-writer`."
- S5. Profiles (issue #1, scope 4): "Document installation for both the `web` and `headless` profiles."
- S6. Tests (issue #1, scope 5): "Automated checks for the bundle layout, skill frontmatter validity, and the persona text (no `{{` template markers)." `npm test` passes.
- S7. Acceptance (issue #1): "`dsh plugin --profile web add <checkout>` works and `--dump-config` shows the `gentle-ai-dsh` layer." "With `engram` absent from `PATH`, dsh boots and the persona and skills still load." "README and `docs/` describe install, removal, the Engram requirement and content sync."
